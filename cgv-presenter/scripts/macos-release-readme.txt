CGV Presenter for macOS
========================

Install steps
-------------
1. Unzip this folder.
2. Double-click "Install CGV Presenter".
3. Click Install in the dialog boxes.

If macOS says the installer is damaged or blocked
--------------------------------------------------
This is a normal macOS security message for apps distributed outside the App Store.

Try this:
1. Right-click "Install CGV Presenter".
2. Choose Open.
3. Click Open again in the confirmation dialog.
4. Run the installer.

After installation, open "CGV Presenter" from your Applications folder.
