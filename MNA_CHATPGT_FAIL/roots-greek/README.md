# ROOTS Greek Dataset

This folder is the reset point for the ROOTS structural dataset.

## Principle

Greek owns all structure.

No Spanish alignment is used in this layer.
No NBLA token ownership is used in this layer.
No reverse-interlinear logic is used in this layer.

## Sources

The Greek-only layer is based on:

- Greek token order
- Greek surface form
- lemma
- MorphGNT morphology
- RMAC output codes

## Output conventions

- `### verse reference`
- `cn1.` = connector 1
- `C1.` = clause 1
- `[F]` = finite verb
- `[NF]` = non-finite verb

## Current phase

Phase 1 is Greek-only extraction and rendering.

The first goal is not final syntax perfection. The first goal is to create a clean Greek-only structural base that can be audited without Spanish corruption.

Spanish output will be added only after the Greek layer is stable.
