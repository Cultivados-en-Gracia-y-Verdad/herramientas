This document exists because the MNA project experienced major architectural drift during implementation.

The drift became visible when:

- undocumented concepts entered the system,
- implementation expanded beyond operational definitions,
- “objective” language exceeded mechanically verified claims,
- connectors became structurally inflated,
- undocumented abstractions replaced documented mechanics.

This document serves as:

- failure documentation,

- anti-drift safeguard,
- reconstruction foundation,
- permanent audit record.
